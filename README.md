# taskflow_backend

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run dev
```

To build and start:

```bash
bun run build
bun run start
```

To type check:

```bash
bun check
```

This project was created using `bun init` in bun v1.4.3. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
